1. 플러그인 대화와 입력 정보

이 플러그인은 유튜브 주제 기획을 위해 나이, 직업, 경험, 관심사, 제작 조건 및 목표 등을 질문합니다. 성별은 선택 항목이며, 모르는 항목은 “모르겠어요”라고 답할 수 있습니다.

운영자는 플러그인 대화나 사용자가 입력한 정보를 별도 시스템으로 수집·저장하거나 다른 업체에 전달하지 않습니다. 플러그인에는 운영자가 관리하는 외부 서버 연결이 없습니다.

ChatGPT 또는 Codex에서 입력·처리되는 대화 정보에는 해당 서비스의 개인정보 정책과 사용자 설정이 적용됩니다. 운영자의 별도 수집 여부와 서비스 제공자의 정보 처리는 구분됩니다.

2. 고객지원 이메일

이메일 문의 시 회신 주소, 이메일에 표시되는 발신자 이름, 문의 내용과 사용자가 보내는 첨부파일을 문의 확인 및 답변 목적으로 처리합니다. 필요한 내용만 보내주시기 바랍니다.

운영자는 문의 이메일을 처리 후 10일 이내 삭제합니다. 문의 전송과 수신에는 Google의 Gmail 서비스가 사용되며, 해당 서비스의 정보 처리에는 Google의 정책이 적용됩니다.

3. 공식 안내 사이트

이 사이트는 소개와 안내문을 제공하는 정적 페이지입니다. 운영자가 별도로 설치한 방문 분석 도구, 광고 추적 코드, 회원가입 또는 개인정보 입력 양식은 없습니다.

사이트 호스팅이나 이용 중인 서비스에서 접속 처리 및 보안을 위해 처리하는 정보는 각 서비스의 정책을 따릅니다.

이 안내 사이트는 GitHub Pages에서 제공됩니다. GitHub는 보안을 위해 방문자의 IP 주소를 기록·보관한다고 안내하고 있으며, 이 정보 처리에는 GitHub의 개인정보처리방침이 적용됩니다.
